# Golan IPTV Pro

[English](README.md)


مشغّل IPTV مبني بـFlutter لهواتف Android وAndroid TV. الإصدار **4.6.0+9**؛ رقم إصدار APK المنفصل ARM64 هو **2009**، والمعرّف `com.golan.iptv.golan_iptv_pro`.

## التنزيل والتثبيت

نزّل APK الحالي **ARM64 Debug** وأرشيف المصدر الكامل من [الإصدارات](https://github.com/dark9guna/golan-iptv-pro/releases). فك ضغط المصدر قبل البناء. يحتاج APK جهاز ARM64 ونظام Android 7 / API 24 فأحدث. الملف تطويري ونُسخ دون تغيير؛ تحديث نسخة مثبتة يحتاج توقيعًا مطابقًا.

```powershell
adb install -r Golan-IPTV-Pro-arm64-debug.apk
```

## الوظائف

- إدخال M3U/Plus وHLS/TS المباشر وXtream Codes وStalker MAC ورمز التفعيل، وأدوار للسيرفرات وتحويل احتياطي للقناة المطابقة.
- مشغّل مستمر أثناء التصفح وملء الشاشة ودرج القنوات والنافذة المصغرة داخل التطبيق، وقنوات حديثة وتنقل سريع وصوت خلفي بخدمة Android أمامية.
- العربية والإنجليزية ورقابة أبوية وتصفية بيانات وصفية وتحديث القنوات والتحقق منها وخيارات التخزين المؤقت وتشخيص الشبكة.
- حفظ بيانات الاشتراك عبر Flutter secure storage وAndroid Keystore مع إخفائها في الواجهة ودون بديل نصي عند تعطل التخزين الآمن.

## الاشتراكات التجريبية والحدود

لا يوجد اشتراك مدفوع حقيقي أو خادم تفعيل مرفق. عند ترك عنوان التفعيل فارغًا، يفتح `111222` / `GOLAN-VIP` قائمة **VIP محاكاة**، ويفتح `999000` / `GOOGLE-TEST` مصادر اختبار معزولة. لا تمنح هذه الرموز اشتراكًا مدفوعًا. أدخل اشتراكك المصرح به أو وصّل خادم HTTPS وفق `Documentation/Device-Activation-API.md`. قد تتغير المصادر العامة أو تتوقف، ولا تمنح الحزمة حقوق إعادة البث أو الوصول للمحتوى المقيد.

النافذة المصغرة داخل التطبيق. الإرجاع يتبع مجال الوسائط والتخزين المؤقت، ومؤشر التأخير يقيس استجابة HTTP للكتالوج ولا يضمن تأخير البث. التصفية تعتمد على البيانات الوصفية وقد لا تصنف كل محتوى. لا يوجد ادعاء بتدقيق أمني مستقل.

## البناء من المصدر

يلزم Flutter يوفر Dart `^3.13.5` وJDK 21 وإصدارات SDK/NDK التي تحددها أدوات Flutter وGradle. ابدأ من جذر المصدر المستخرج الذي يحتوي `pubspec.yaml`، مع اتصال لاستعادة الاعتماديات.

```powershell
flutter pub get
flutter build apk --debug --target-platform android-arm64 --split-per-abi
```

يمكن استخدام `scripts/flutter.ps1` مع Flutter على PATH أو إعداد SDK محلي خاص. لبناء Release عيّن قيمك الخاصة للمتغيرات `GOLAN_KEYSTORE` و`GOLAN_STORE_PASSWORD` و`GOLAN_KEY_ALIAS` و`GOLAN_KEY_PASSWORD`. المفاتيح وإعدادات الجهاز غير مرفقة. بقيت الاختبارات الأصلية، لكن لم يُنفذ بناء أو اختبار وظيفي جديد لتجهيز النشر.

الشهادة والمفتاح في `test/fixtures/localhost.*` مواد TLS عامة **للاختبار المحلي فقط**، وليسا بيانات خدمة إنتاج؛ لا تستخدمهما للإنتاج. راجع `THIRD_PARTY.md` و`THIRD_PARTY_NOTICES.txt` و`LICENSE_STATUS.md` و`PRIVACY.md`. لم تُختر رخصة جديدة لشيفرة مالك التطبيق.
